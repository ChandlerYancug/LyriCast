**LyriCast 1.0**：第一个正式版 —— 调试通道验证通过，内容转正并做完最后收尾。

## 这一版改了什么

- **唱臂去掉所有投影**（管身 / 配重 / 轴承座）：细长物体在俯视画面里投出硬边
  影子，像“第二支臂”，看着奇怪；现在唱臂干净地浮在盘面上。
- **同一张专辑的歌不再张张同色**：封面主色定“色系”，每首歌再在色系里按歌名
  固定挑一款（暖橙 → 琥珀 / 正红 / 大理石；暗色 → 黑胶 / 星云 / 闪粉……）——
  切歌能看到唱片换一张，同一首歌永远同款。
- **手动换过的彩胶一直保留**（记在 `song_skins`，下次放这首直接恢复）；
  手动换只影响这一首，其它歌继续按各自封面自动配。
- **切歌不再闪一下黑胶**：新歌封面还没到时先留着上一张，到了再交叉淡入。
- 本版还包含调试通道的全部内容：
  - 彩胶按专辑封面主色自动配
  - 唱臂按俯视重画（管身金属渐变、唱头架 / 唱头 / 针尖都按真臂的观感）
  - 网易云 OST 类歌词不再把「作词 / 作曲」制作人员表当成歌词显示
  - 日志默认安静（托盘里按需开启，未捕获异常仍会记录）
  - 点桌面快捷方式不再闪命令行黑框（Python 3.13.0 venv 的已知问题已绕过）
  - Apple 凭证图形化获取；源码版 / exe 版的凭证互通

## 下载与使用

- 下载 `LyriCast-v1.0.0-win64.zip`（Windows 64 位免安装版），解压后双击 `LyriCast.exe`。
- 数据与配置在 `%LOCALAPPDATA%\LyriCast\`（与源码版互通，凭证会自动搬运）。
- 源码用户：`git clone` 后双击 `run.bat` 即可（首次自动建 .venv）。
- 完整改动见 [CHANGELOG.md](https://github.com/ChandlerYancug/LyriCast/blob/main/CHANGELOG.md)。
